# Profile: custody-ops

For an operator who already runs hot wallets and wants the outstanding authority visible.

- Wallet entries are attested by the statement `I operate these`. That is not a signature. The brief says so.
- On-chain watch is read-only RPC. Tier-0 is a code or delegation change, a new destination, or a limit breach.
- Pre-authorization book stores fingerprints and revocation paths. It rejects key material.
- Freeze playbook `hot-wallet-drain` prefills issuer drafts. The operator sends them.
- Sentinel never constructs a transaction.

The 29 October 2026 hot-wallet event's root cause is undisclosed. Drills treat delegation as a page condition, not as a proven cause.
