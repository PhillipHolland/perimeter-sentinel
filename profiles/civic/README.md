# Profile: civic

For an office that publishes pages: lookup, registration status, results. Availability and integrity only.

- Behavioral telemetry stays off. Config rejects the civic profile when that flag is on.
- No eligibility decision, no content decision, no voting-system connection.
- Freeze desk contacts to fill: `status-page`, `cdn`, `cisa-region`. Drafts only.
- A surge on a results page is not automatically a swarm. Declare the calendar. IP-only correlation is `needs_human`.

This profile does not secure an election.
